# 01：硬件与模型

目标是原版 Qwen3.8-Flash-Next 的 GSQ-RCO GGUF，由 Strata 在系统内存和 GPU 上协同运行。GGUF 量化与 KV 精度分别配置。

## 基本环境

- Windows 10/11，或 Linux；Ubuntu 22.04 / 24.04 可作为目标环境。
- NVIDIA RTX 20 / 30 / 40 / 50 系列；上游推荐至少 12GB 显存。双卡时每张卡仍需单独满足引擎支持要求。
- 核对版本的安装器要求 NVIDIA 驱动主版本至少 580，配套 CUDA 13.0 运行库。
- Python 64 位，至少 3.10；Windows 启动入口在缺少 Python 时尝试安装 3.12。
- 建议 NVMe SSD。选择 IQ3_S 时预留约 150GB 空间，覆盖模型、MTP、pack 及临时文件。

## 原模型量化档

以下数字来自核对版本 `setup.py`，是安装器估算，不是本次测试测量。

| 量化 | 安装器估计下载量 | 专家 arena 估算 | 安装器建议内存 |
|---|---:|---:|---:|
| Q2_0 | 66.4GB | 34.0GB | 48GB |
| IQ2_XS | 68.0GB | 35.5GB | 48GB |
| IQ3_XXS | 75.8GB | 42.9GB | 60GB |
| IQ3_S | 83.6GB | 50.3GB | 62GB |

程序还有低内存路径，会把专家映射到文件并利用显存缓解内存压力；具体适配还涉及 pack 格式及空闲显存，不能据此承诺小内存机器的速度。优先使用常规内存方案。

## 上下文

安装菜单提供：8192 / 32768 / 65536 / 131072 / 262144 token。262144 就是通常称作 256K 的满档，上游菜单有时简称 262K。

原包将 IQ3 系列满档要求写成固定 90GB。此次核对的源码已改为按以下公式估计：

```text
专家 arena 估算 + context × 13 × 1056 / 1e9 + 24
```

IQ3_S 在 262144 档得到约 78；若安装器检测到的系统内存低于该数值，会将 IQ3_S / IQ3_XXS 的超过 131072 档降回 131072。源码的内存检测按 GiB，而公式中有十进制换算，部署时应以它实际打印的结果为准。

为了给系统和其他进程留余量，IQ3_S 满档可先以 **96–128GB 内存**为目标；128GB 通常更从容。64GB 的常规方案先选 IQ2_XS / Q2_0，或者 IQ3_S 的 128K，最终按启动日志及换页情况决定。

## 单卡与双卡

| 机器 | 初始配置建议 |
|---|---|
| 单卡 48GB，96–128GB 内存 | IQ3_S；先验收 128K，再验证 262144；视觉开启 |
| 双 RTX 3090 24GB，96–128GB 内存 | `--gpus 0,1`，自动按层分配；同样先验证上下文 |
| 双 RTX 3080 20GB，64GB 内存 | 先用 IQ2_XS；`--gpus 0,1`；上下文由实际启动分配及长文验证决定 |
| 双 RTX 3080 20GB，96–128GB 内存 | 可尝试 IQ3_S，但速度、显存余量和满档能力需要实测 |

双卡采用按层流水线分配，系统内存中的专家池由两张卡共享；每张卡仍有自己的固定权重、KV 与工作区开销。总显存相加不等于一张同容量显卡，也不保证双卡解码速度更快。
